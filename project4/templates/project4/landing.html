Project 4 - Preference Elicitation

A user study comparing two ways of eliciting a new user's movie preferences: repeated pairwise comparisons vs. ranking lists of ten movies at a time, built on the IMDB 5000 Movie Dataset.

↓ Download PDF Report Start the Study ->

Task 1 & 2 - Model

Movies are represented by ~30 standardized features (genre, rating, cast/director popularity, quality, recency). Preferences follow a linear utility U(x) = wTx under a Bradley-Terry choice model, extended to full rankings via Plackett-Luce.

Task 3 - Study design

A within-subjects, counterbalanced study: every participant tries both interaction styles, then a shared held-out block measures which method's fitted preferences better predict their real choices. Full protocol, hypotheses, and analysis plan are in the PDF report.

Task 4 - This interface

The "Start the Study" button opens the exact interface a real participant would use - consent, both conditions, questionnaires, and a debrief with a completion code - ready to run without further modification.

Section 4 — Extension (beyond the required tasks)

The report closes with two extensions. First, an adaptive item-selection rule (Bayesian D-optimal design over the Bradley-Terry posterior), which the assignment flags as an interesting direction: on simulated participants it learns a preference vector from noticeably fewer comparisons than uniform random sampling. Second, a simulation-based power analysis that re-derives the sample size from the outcome measure the study actually records, rather than from an assumed effect size — and finds the original N would be too small. Neither runs during a participant session; the study itself uses random selection exactly as specified.
